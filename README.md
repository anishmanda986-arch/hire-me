# Hire Me

A premium, mobile-first professional-services app for discovering services, describing a brief, requesting a quote, communicating, and tracking delivery.

## Included

- Dark blue / sky blue / white visual system
- Custom H + M connection logo
- Splash screen and 3-screen onboarding
- Home hero with fast quote flow
- Smart request flow: brief → analysis → preliminary estimate
- Services, projects, messages, profile, reviews and settings
- Glassmorphism cards and atmospheric background
- Android APK built by GitHub Actions

## Build

```bash
./gradlew assembleRelease
```

The APK is produced at `app/build/outputs/apk/release/app-release.apk`.

> Estimates in the prototype are clearly labelled preliminary; the final quote remains manual.
